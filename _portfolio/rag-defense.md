Designed a defense framework for Retrieval-Augmented Generation (RAG) systems facing external data extraction attacks. The method monitors hidden-layer representations before generation to identify attack intent and reduce token leakage risk. This project ranked 22nd in the Datacon RAG track, and the related paper is under submission.
