Built machine learning models to quantify and predict momentum in tennis matches. The project used Attention-BiLSTM-BiGRU for momentum modeling and XGBoost for match swing prediction, with feature engineering and time-series cross-validation.

This project received Honorable Mention in MCM/ICM 2024.
